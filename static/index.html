Import sold comps

Paste an export from 130point, Terapeak/Seller Hub, or any spreadsheet of sales. Needs a Price column plus either a Player column (best — add a Card # column too for exact matches) or a free-text Title column. A Date column (any common format) powers the price-history chart.
